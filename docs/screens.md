# CAI Notice 화면 설계서

## 1. 홈 화면

### 목적

홈 화면은 사용자가 CAI Notice 서비스를 처음 접하는 화면이다.
서비스의 목적을 간단히 소개하고, 사용자가 자신의 학과를 선택한 뒤 공지 목록 화면으로 이동할 수 있도록 한다.

### 주요 요소

* 서비스 이름: CAI Notice
* 서비스 소개 문구
* 학과 선택 박스
* 시작하기 버튼

### 화면 예시

```text
CAI Notice

동국대학교 공지를 더 쉽게 확인하세요.

학과를 선택해주세요.
[ 컴퓨터공학과 ▼ ]

[ 시작하기 ]
```

### 설명

1차 버전에서는 사용자 로그인을 사용하지 않는다.
사용자가 선택한 학과 정보를 기준으로 내 학과 공지 목록을 필터링한다.

---

## 2. 공지 목록 화면

### 목적

공지 목록 화면은 CAI Notice의 핵심 화면이다.
사용자는 이 화면에서 전체 공지와 내 학과 공지를 확인하고, 검색 및 카테고리 필터를 사용할 수 있다.

### 주요 요소

* 상단 헤더
* 검색창
* 공지 탭
* 카테고리 필터
* 공지 카드 목록

### 공지 탭

* 전체 공지
* 내 학과 공지

### 카테고리 필터

* 전체
* 학사
* 장학
* 학과
* 일반
* 비교과

### 화면 예시

```text
CAI Notice

[ 공지 검색하기... ]

[ 전체 공지 ] [ 내 학과 공지 ]

카테고리:
[ 전체 ] [ 학사 ] [ 장학 ] [ 학과 ] [ 일반 ] [ 비교과 ]

--------------------------------
[학사]
2026학년도 2학기 수강신청 안내

작성일: 2026-06-11
학과: 전체
출처: 동국대학교 학사공지

[ 원본 공지 보기 ]
--------------------------------

--------------------------------
[학과]
컴퓨터공학과 졸업요건 안내

작성일: 2026-06-12
학과: 컴퓨터공학과
출처: 컴퓨터공학과 홈페이지

[ 원본 공지 보기 ]
--------------------------------
```

### 설명

사용자가 전체 공지 탭을 선택하면 수집된 모든 공지를 보여준다.
사용자가 내 학과 공지 탭을 선택하면 사용자가 선택한 학과와 관련된 공지를 보여준다.

예를 들어 사용자가 컴퓨터공학과를 선택한 경우 다음 공지가 표시된다.

* 학과가 `전체`인 공지
* 학과가 `컴퓨터공학과`인 공지

---

## 3. 공지 카드

### 목적

공지 카드는 공지 하나의 핵심 정보를 간단하게 보여주는 UI 요소이다.
사용자는 공지 카드를 보고 필요한 공지인지 빠르게 판단할 수 있다.

### 주요 요소

* 카테고리
* 공지 제목
* 작성일
* 학과
* 출처
* 원본 공지 링크 버튼

### 화면 예시

```text
[학사]

2026학년도 2학기 수강신청 안내

작성일: 2026-06-11
학과: 전체
출처: 동국대학교 학사공지

[ 원본 공지 보기 ]
```

### 설명

공지 카드에는 너무 많은 내용을 넣지 않고, 사용자가 빠르게 확인해야 하는 정보만 보여준다.
자세한 내용은 원본 공지 링크를 통해 확인할 수 있도록 한다.

---

## 4. 공지 상세 화면

### 목적

공지 상세 화면은 선택한 공지의 자세한 내용을 보여주는 화면이다.

단, 1차 버전에서는 필수 화면이 아니다.
개발 범위를 줄이고 싶다면 공지 상세 화면 없이 원본 공지 링크로 바로 이동하도록 구현할 수 있다.

### 주요 요소

* 공지 제목
* 카테고리
* 학과
* 작성일
* 출처
* 공지 본문
* 원본 공지 링크 버튼

### 화면 예시

```text
2026학년도 2학기 수강신청 안내

카테고리: 학사
학과: 전체
작성일: 2026-06-11
출처: 동국대학교 학사공지

공지 본문 내용...

[ 원본 공지 보기 ]
```

### 설명

공지 상세 화면을 만들 경우, 사용자는 CAI Notice 안에서 공지 본문을 확인할 수 있다.
하지만 정확한 내용 확인을 위해 원본 공지 링크는 항상 제공해야 한다.

---

## 5. 1차 버전 화면 흐름

```text
홈 화면
↓
학과 선택
↓
공지 목록 화면
↓
전체 공지 / 내 학과 공지 선택
↓
검색 또는 카테고리 필터 사용
↓
원본 공지 보기
```

---

## 6. 1차 버전 필수 화면

1차 버전에서 반드시 구현할 화면은 다음과 같다.

* 홈 화면
* 공지 목록 화면

공지 상세 화면은 선택 사항이다.

---

## 7. 1차 버전에서 제외할 화면

1차 버전에서는 다음 화면을 구현하지 않는다.

* 로그인 화면
* 회원가입 화면
* 마이페이지
* 관리자 페이지
* AI 챗봇 화면
* 알림 설정 화면
* 푸시 알림 화면
