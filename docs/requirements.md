# CAI Notice 기능 명세서

## 1. 프로젝트 개요

CAI Notice는 동국대학교 학생들이 학교 공지와 학과 공지를 더 쉽게 확인할 수 있도록 돕는 웹 서비스이다.

동국대학교의 공지는 학교 홈페이지, 학과 홈페이지 등 여러 게시판에 흩어져 있어 학생이 본인에게 필요한 공지를 놓치기 쉽다.
CAI Notice는 이러한 공지를 한곳에서 확인할 수 있도록 정리하고, 검색 및 필터 기능을 제공하는 것을 목표로 한다.

## 2. 1차 버전 목표

1차 버전에서는 AI, 로그인, 학교 공식 시스템 연동 없이 공지 조회 기능에 집중한다.

사용자는 다음 기능을 사용할 수 있다.

* 전체 공지 조회
* 내 학과 공지 조회
* 키워드 검색
* 카테고리 필터
* 원본 공지 링크 이동

## 3. 대상 사용자

CAI Notice의 주요 대상 사용자는 동국대학교 재학생이다.

특히 다음과 같은 학생을 대상으로 한다.

* 학교 공지를 자주 확인해야 하는 학생
* 학과 공지를 놓치고 싶지 않은 학생
* 장학, 학사, 비교과, 졸업요건 등 필요한 공지를 빠르게 찾고 싶은 학생

## 4. 핵심 기능

### 4.1 전체 공지 조회

사용자는 수집된 전체 공지 목록을 확인할 수 있다.

각 공지에는 다음 정보가 표시된다.

* 공지 제목
* 카테고리
* 학과
* 출처
* 작성일
* 원본 공지 링크

### 4.2 내 학과 공지 조회

사용자는 자신의 학과를 선택할 수 있다.

선택한 학과에 따라 다음 공지를 확인할 수 있다.

* 전체 학생 대상 공지
* 선택한 학과와 관련된 공지

예를 들어 사용자가 컴퓨터공학과를 선택한 경우, 전체 공지와 컴퓨터공학과 관련 공지를 함께 확인할 수 있다.

### 4.3 공지 검색

사용자는 검색어를 입력하여 공지를 검색할 수 있다.

검색 대상은 다음과 같다.

* 공지 제목
* 공지 내용
* 카테고리
* 학과
* 출처

### 4.4 카테고리 필터

사용자는 카테고리별로 공지를 필터링할 수 있다.

초기 카테고리는 다음과 같이 설정한다.

* 학사
* 장학
* 학과
* 일반
* 비교과

### 4.5 원본 공지 링크 이동

각 공지에는 원본 공지 페이지로 이동할 수 있는 링크를 제공한다.

사용자는 CAI Notice에서 공지를 확인한 뒤, 정확한 내용은 원본 공지 페이지에서 다시 확인할 수 있다.

## 5. 공지 데이터 구조

공지 하나는 다음 정보를 가진다.

* id
* 제목
* 카테고리
* 학과
* 출처
* 작성일
* 원본 링크
* 본문 내용

예시 데이터는 다음과 같다.

```json
{
  "id": 1,
  "title": "2026학년도 2학기 수강신청 안내",
  "category": "학사",
  "department": "전체",
  "source": "동국대학교 학사공지",
  "date": "2026-06-11",
  "url": "https://www.dongguk.edu/...",
  "content": "공지 본문 내용"
}
```

## 6. 1차 버전에서 제외할 기능

1차 버전에서는 다음 기능을 포함하지 않는다.

* AI 요약
* 챗봇
* 사용자 로그인
* e-Class 연동
* nDRIMS 연동
* 학교 공식 로그인 연동
* 푸시 알림
* 실시간 공지 알림

## 7. 예정 기술 스택

현재 예정된 기술 스택은 다음과 같다.

* 프론트엔드: React + Vite
* 백엔드: Spring Boot
* 데이터베이스: MySQL
* 크롤러: Python
* 서버: AWS EC2 Ubuntu
* 웹 서버: Nginx
* 도메인: Gabia
* HTTPS: Let's Encrypt

## 8. 개발 순서

CAI Notice는 다음 순서로 개발한다.

1. 프로젝트 문서 정리
2. 프론트엔드에서 임시 공지 데이터로 화면 구현
3. 공지 목록, 검색, 필터 기능 구현
4. 백엔드 API 구현
5. 프론트엔드와 백엔드 연결
6. 데이터베이스 설계 및 연결
7. 공지 크롤러 구현
8. AWS EC2 서버 배포
9. 도메인 연결 및 HTTPS 적용
