# CAI Notice

CAI Notice is a notice collection and recommendation service for Dongguk University students.

## Overview

Dongguk University notices are posted across multiple boards, such as academic notices, scholarship notices, general notices, and department notices. Because of this, students may miss important information that is relevant to them.

This project aims to collect public notices from Dongguk University websites and provide a simple way for students to search, filter, and find notices based on their interests.

## Main Features

* View university notices in one place
* Filter notices by category
* Search notices by keyword
* Save or manage interest keywords
* Recommend notices based on user interests
* Provide links to original notice pages

## Project Scope

This project focuses on public notice collection and user-friendly notice browsing.

The following features are not included in the initial version:

* AI-based summarization
* e-Class integration
* nDRIMS login integration
* Official university system integration
