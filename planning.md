# CAI Notice Planning

## Problem

Dongguk University notices are scattered across multiple websites and boards, making it difficult for students to find notices that are relevant to them.

## Target Users

Dongguk University students.

## Initial Features

- View all notices
- View department-specific notices
- Search notices by keyword
- Filter notices by category
- Open original notice links

## Excluded From Initial Version

- AI summarization
- Chatbot
- e-Class integration
- nDRIMS integration
- Official school login integration
